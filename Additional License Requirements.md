1.2. **Access Logging**: All access to the source code repositories must be logged with timestamped records of:

   - Actions performed (read, write, copy, etc.)

1.3. **Segmented Access**: Source code access must be segmented so that consultants and third parties only have access to components absolutely necessary for their assigned tasks.
